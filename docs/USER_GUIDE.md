# User guide

- **Open apps:** double-click a desktop icon or use the Start/app launcher. Single-click selects an icon.
- **Manage windows:** drag the title bar; use the title-bar buttons to minimize, maximize/restore and close. Taskbar buttons toggle window visibility.
- **Explorer:** double-click folders to enter; double-click files to open in Notepad. Use New folder/New file. Right-click an item for rename/delete.
- **Notepad:** edit the text and Save. Save as changes the virtual path.
- **Terminal:** supported commands are `help`, `clear`, `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cat`, `echo`, `date`, and `rm`. These affect only the simulated workspace.
- **Calculator:** use the on-screen buttons; supported arithmetic includes parentheses and +, -, ×, ÷.
- **HTML Studio:** edit HTML, Run preview, and Save file. Preview is in a sandboxed iframe.
- **Settings:** export/import a JSON workspace backup or reset the virtual workspace.

The workspace is browser-local. It is not synchronized across browsers or devices.
